## Creating a theme from scratch

For a new project with no existing themes, designers create a theme in Tokens Studio for Figma.

## Duplicating an existing theme

In a project with at least one existing theme, the quickest way to create a new theme is to duplicate an existing one. There isn't a mechanism for this in Tokens Studio for Figma, but developers are able to duplicate and edit themes within the codebase.

## Adding new typography

Designers provide font files. Developers convert the font files and write the CSS to incorporate them into the design system. We have no programmatic way of doing this; it's a manual task.
